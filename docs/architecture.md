# البنية — لقطة (Laqta)

تطبيق مونتاج فيديو وصوت، عربي أولاً، لأندرويد أولاً. كل المعالجة تتم على
الهاتف. **لا يوجد سيرفر ولا Firebase** حالياً.

## الطبقات

```
lib/
  main.dart              ← نقطة البداية، الثيم، اللغة العربية (RTL)
  core/project/          ← نموذج المشروع: Dart خالص، بدون Flutter، مختبَر بالكامل
    clip.dart            ← مقطع واحد: ملف المصدر + نطاق القص
    edit_project.dart    ← المشروع: قائمة مقاطع مرتّبة + إعدادات التصدير + العمليات
    export_aspect.dart   ← مقاسات التصدير 9:16 / 16:9 / 1:1
  core/history/          ← EditHistory: تراجع/إعادة عام فوق لقطات غير قابلة للتعديل
  core/storage/          ← ProjectRepository: ملف <id>.json لكل مشروع
  core/ids.dart          ← توليد معرّفات آمنة كأسماء ملفات + isSafeId
  features/editor/       ← EditorController (Riverpod): التعديلات + التاريخ + الحفظ التلقائي
  (مخطط) features/…      ← الشاشات: الرئيسية، المحرر، التصدير
  (مخطط) engine/         ← جسر Dart ↔ Kotlin إلى محرك Media3
android/app/src/main/kotlin/  ← (مخطط) تنفيذ المعالجة عبر Media3 Transformer
```

## المبادئ
- **النموذج غير قابل للتعديل (immutable):** كل عملية (قص، تقسيم، نقل، حذف)
  ترجع مشروعاً جديداً. هذا يجعل التراجع/الإعادة سهلاً ويمنع أخطاء الحالة.
- **الملف الأصلي لا يُلمس أبداً:** المقطع يسجّل فقط أي جزء من المصدر يُستخدم.
- **المشروع = مستند JSON:** يُحفظ على الهاتف، وهو نفسه ما يُرسَل للمحرك عند
  التصدير. الحقل `schemaVersion` إلزامي؛ أي تغيير في الشكل يرفع الرقم ويضيف
  ترحيلاً (migration) مع اختبار.
- **الأزمنة بالميكروثانية** (`...Us`) في JSON لتجنّب أخطاء الكسور.
- **النص العربي يُرسم في Flutter** ثم يُحوَّل لصورة شفافة تُركَّب فوق الفيديو،
  لأن `drawtext` في FFmpeg يقطّع الحروف العربية ويعكس الاتجاه.

## الحالة والحفظ
- `EditorController` يطبّق كل تعديل على النموذج، ويضيفه للتاريخ (100 خطوة)،
  ثم يحفظ تلقائياً. عمليات الحفظ تُنفَّذ بالتسلسل، فلا تسبق نسخةٌ قديمة نسخةً أحدث.
- تعديل غير صالح يرمي `ArgumentError` ولا يغيّر الحالة. فشل الحفظ لا يوقف التطبيق
  بل يظهر في `EditorState.saveError`.
- المشاريع في `<documents>/projects/<id>.json`، والكتابة ذرّية (ملف مؤقت ثم rename).
- المعرّف يُتحقق منه بـ`isSafeId` قبل أي عملية على الملفات، لمنع الخروج من المجلد (`../`).
- الملف التالف يظهر في `unreadable` عند العرض، ولا يُحذف أبداً تلقائياً.
- `projectRepositoryProvider` يُمرَّر في `main.dart`، ويُستبدل في الاختبارات بمجلد مؤقت.

## شكل ملف المشروع (schemaVersion 1)

```json
{
  "schemaVersion": 1,
  "id": "p1",
  "name": "رحلتي",
  "aspect": "portrait",
  "clips": [
    {
      "id": "a",
      "sourcePath": "/storage/.../a.mp4",
      "sourceDurationUs": 10000000,
      "trimStartUs": 1000000,
      "trimEndUs": 4000000
    }
  ]
}
```

قواعد: معرّفات المقاطع فريدة، وأقصر مقطع 100ms، و`0 ≤ trimStart < trimEnd ≤ sourceDuration`.
الموضع على حدّ بين مقطعين يتبع المقطع التالي.

## محرك المعالجة
- **Media3 Transformer** (Google، يستخدم معالج الفيديو في الجهاز): قص، دمج،
  سرعة، تأثيرات، خلط صوت. يُستدعى عبر platform channel من Kotlin.
- `ffmpeg_kit_flutter` الأصلي متوقف منذ 2025، فلا تستخدمه. وFFmpeg عبر نسخة
  مجتمعية احتياطي فقط لما لا يدعمه Media3، وانتبه لرخصة GPL/LGPL.

## الصلاحيات والخصوصية
- لا صلاحيات تخزين واسعة: نستخدم منتقي الوسائط (Photo Picker) أو
  `READ_MEDIA_VIDEO` و`READ_MEDIA_AUDIO`. ولا `MANAGE_EXTERNAL_STORAGE` أبداً.
- `RECORD_AUDIO` فقط عند إضافة التعليق الصوتي، ويُطلب وقت الاستخدام.
- أي تعديل على `AndroidManifest.xml` محمي بخطاف ويحتاج موافقة مصطفى.
- الملفات المؤقتة (التصدير، الصوت المستخرج، صور النصوص) تُحذف بعد الاستخدام.
- لا رفع لأي وسائط ولا تحليلات بدون موافقة صريحة من المستخدم.
