# البنية — استوديو المونتاج

```
studio/
  config.py      ← الصوت الافتراضي (Leda)، ترتيب نماذج TTS، مقاس الإطار، الخطوط والألوان
  project.py     ← قراءة project.json والتحقق منه (أقسام، مقاطع، بطاقات، بطاقة ختام)
  tts.py         ← Gemini TTS: النص فقط بلا تعليمات؛ ينتقل للنموذج التالي عند نفاد الحصة اليومية
  check.py       ← فحص سمعي: faster-whisper + تغطية الكلمات + سرعة الكلام + كلمات إنكليزية غير متوقعة
  voiceover.py   ← قسم = تسجيل واحد → فحص → تنظيف (وشيش، أطراف) → ربط → timeline.json
  captions.py    ← ترجمة وبطاقات كملف ASS، بلف RTL للأسطر العربية
  render.py      ← مقاطع (تبطيء + تنعيم حركة + رفع دقة) + خلفيات مموّهة + بطاقة ختام → MP4
  media.py       ← أدوات ffmpeg/ffprobe
projects/<اسم>/
  project.json   ← النص والمونتاج (تحت git)
  media/         ← مقاطع مصطفى (خارج git)
  build/         ← الصوت والفيديو الناتج (خارج git)
tests/           ← pytest بلا إنترنت؛ test_render يركّب فيديو صغيراً فعلاً
```

## شكل project.json

```json
{
  "title": "...", "voice": "Leda",
  "sections": [{"id": 1, "lines": [{"say": "ما يُقرأ (قد يحمل تشكيلاً)", "show": "ما يُعرض"}]}],
  "segments": [
    {"kind": "clip",  "src": "v1.mp4", "from": 2.0, "to": 6.0, "start": 0, "end": 4.4},
    {"kind": "still", "src": "v4.mp4", "at": 5.2, "start": 4.4, "end": 8.3},
    {"kind": "blur",  "src": "v4.mp4", "start": 8.3, "end": 12.0},
    {"kind": "end",   "src": "v2.mp4", "start": 12.0, "end": -1}
  ],
  "cards": [{"start": 29.9, "end": 33.2, "text": "سطر\\Nسطر"}],
  "end_card": {"title": "...", "tagline": "...", "cta": "...", "sub": "...", "hold": 2.6}
}
```
- المقاطع متصلة بلا فجوات؛ مع بطاقة الختام يكون آخرها `end: -1` (حتى نهاية الفيديو).
- الأزمنة ثابتة بالثواني: إذا أُعيد توليد الصوت فتغيّر طوله، `render` يرفض ويطلب تحديث project.json.
- `src` اسم ملف داخل `media/` فقط (لا `/` ولا `..`).
- `clip`: يُبطَّأ ليملأ مكانه (حتى ×1.3 طبيعي)؛ `from`/`to` لاستخدام جزء منه فقط.
- `still`: إطار ثابت من الثانية `at` بحركة كاميرا بطيئة. **عندما لا يكون صوت الراوية صوت
  الشخص الظاهر**، اختر إطاراً فمه فيه مغلق (افحص لقطات قريبة للفم كل 0.25 ث) — هكذا لا يظهر
  عدم تطابق الشفاه.
- عدد إطارات كل مقطع يُحسب من الحدود التراكمية، فلا ينزاح الفيديو عن الصوت.

## الفحص السمعي (check.py) — لماذا هذه العتبات
مقيسة على تسجيلات حقيقية من إعلان الحرفة:
- **سرعة الكلام:** التسجيلات السليمة 9.0–11.7 حرف/ثانية؛ التي قرأت تعليماتها أيضاً 3.6–7.3. العتبة 8.0.
- **التغطية:** ≥ 60% من كلمات القسم و≥ 50% من كلمات **كل سطر** (السطر المحذوف بالكاد يغيّر نسبة القسم: 24 كلمة − 3 = 87%). المطابقة مرنة لأن whisper يكتب العراقية بأخطاء.
- **إنكليزي غير متوقع:** 3 كلمات فأكثر (التعليمات جُمل؛ اسم علامة مثل "Google Play" مسموح).

## الخدمات الخارجية
| الخدمة | المضيف | الاستخدام |
|---|---|---|
| Gemini TTS | generativelanguage.googleapis.com | صوت الراوية. المفتاح يحقنه وكيل البيئة |
| Hugging Face | huggingface.co | تحميل نموذج faster-whisper (small) مرة واحدة |

- الحصة المجانية: ~10 طلبات صوت يومياً لكل نموذج. الموسيقى (Lyria) غير متاحة في الخطة المجانية.
- لا يُرفع أي فيديو أو صوت لمصطفى إلى خدمة خارجية.

## التعامل مع الأشخاص والأصوات
- لا استنساخ لصوت أو وجه شخص حقيقي بلا موافقة موثّقة.
- لا تعطيل لأي علامة مائية (watermark) يضعها نموذج توليد.
- يُذكّر مصطفى بوسم "محتوى مولّد بالذكاء الاصطناعي" عند النشر.
