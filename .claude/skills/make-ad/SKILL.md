# صناعة إعلان من نص

اتبع الخطوات بالترتيب. لا تولّد شيئاً مدفوعاً أو يستهلك الحصة اليومية قبل موافقة مصطفى على النص.

## 1. النص (مصطفى يكتبه)
- لا تعيد صياغة كلامه. صحّح فقط الأخطاء الواضحة التي تغيّر المعنى (مثل "ثلث" ← "ثلاث") واذكرها له.
- الطول: الإعلان ≤ 80 ثانية ≈ 130–170 كلمة عامية. إن كان أطول فاعرض عليه الخيار قبل التوليد.
- قسّمه إلى أقسام (افتتاحية، جمهور، عرض، ختام). كل قسم = طلب صوت واحد.
- لكلمة قد تُقرأ خطأً: ضع التشكيل في `say` واترك كلامه الأصلي في `show`
  (مثال: `بالحِرْفة` تُقرأ، و`بـ«الحرفة»` تُعرض).

## 2. المشروع
أنشئ `projects/<اسم>/project.json` (انظر `projects/alhirfa-ad/project.json` كمثال):
sections (say/show)، ثم لاحقاً segments وcards وend_card.

## 3. الصوت
```
python -m studio voice projects/<اسم>
```
- الصوت الافتراضي Leda. لا تضع أي تعليمات نبرة داخل النص — النموذج يقرؤها بصوت عالٍ.
- الحصة المجانية ~10 طلبات يومياً لكل نموذج؛ المحرك ينتقل تلقائياً للنموذج التالي.
- إن فشل الفحص السمعي لقسم: احذف `build/voice/s<N>_raw.wav` وأعد التوليد. لا تقصّ يدوياً بالتخمين.
- أرسل `build/voiceover.wav` لمصطفى ليسمعه، مع جدول مدة كل قسم.

## 4. المقاطع (مصطفى يولّدها)
- أعطه لكل قسم: المدة (+1 ث احتياط)، وما يظهر فيه، ونصائح: 9:16، نفس صورة الشخصية،
  "مبتسمة، فمها مغلق، no speech"، الثلث السفلي هادئ للترجمة.
- ضع ملفاته في `projects/<اسم>/media/` وافحصها: المدة، الدقة، ثم إطارات منها لتعرف المحتوى.

## 5. المونتاج
- اكتب `segments` بحيث تغطي الخط الزمني بلا فجوات، و`cards` للوعود المهمة، و`end_card`.
- البطء المقبول للمقطع حتى ×1.3؛ أكثر من ذلك املأه ببطاقة على خلفية مموّهة (`blur`).
```
python -m studio render projects/<اسم>
```
- **قبل الإرسال:** استخرج إطارات من كل قسم وانظر إليها: اتجاه النص العربي، الرموز التعبيرية
  (لا تُعرض — لا تستخدمها)، تداخل النص مع الوجه.

## 6. التسليم
أرسل الفيديو مع: المدة، ترتيب المشاهد، وما لم يُتحقق منه (لم أسمع الصوت بنفسي،
تطابق الشفاه، الموسيقى). ذكّره بتفعيل وسم "محتوى مولّد بالذكاء الاصطناعي" عند النشر.
